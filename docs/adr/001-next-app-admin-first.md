# ADR-001: Next.js 단일 앱과 운영자 콘솔 우선

- 상태: 수용
- 날짜: 2026-09-08

## 결정
화면과 서버 API를 하나의 Next.js App Router 프로젝트로 관리한다. 첫 구현은 캠페인 운영자가 핵심 수치를 빠르게 확인하는 관리자 레이아웃과 P01 실행 기반에 집중한다.

## 이유
실행계획은 24시간 범위에서 HTML 등록부터 신청·성과 확인까지의 흐름을 요구한다. 별도 프론트/백엔드로 나누면 인증·배포·검증 비용이 커지므로 초기에는 단일 앱 경계를 유지한다. 관리자 화면은 장식보다 캠페인 목록, 신청, 방문, 전환율을 먼저 보여준다.

## 영향
P02부터 Supabase 서버 클라이언트와 인증·RLS를 이 구조에 추가한다. 현재 화면의 예시 수치는 실제 DB 연동 전까지 데모 데이터이며 기능 완료 근거로 사용하지 않는다.
