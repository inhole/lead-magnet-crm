# ADR-001: Next.js 단일 앱과 운영자 콘솔 우선

- 상태: 채택
- 날짜: 2026-09-08
- 도입: 커밋 `5b3b78b`. PR 워크플로를 도입하기 전의 초기 구현이다.
- 구현: `src/app`, `src/components/layout/admin-shell.tsx`
- 관련 ADR: [ADR-002](002-supabase-auth-ownership.md), [ADR-007](007-ui-library-and-states.md)

## 결정

화면과 서버 API를 하나의 Next.js App Router 프로젝트로 관리한다. 첫 구현은 운영자가 핵심 수치를 빠르게 확인하는 관리자 레이아웃과 실행 기반 구성에 집중한다.

## 이유

실행계획은 좁은 시간 범위에서 HTML 등록부터 신청·성과 확인까지의 흐름을 요구한다. 프론트엔드와 백엔드를 나누면 인증·배포·검증 비용이 커지므로 초기에는 단일 앱 경계를 유지한다. 관리자 화면은 장식보다 캠페인 목록, 신청, 방문, 전환율을 먼저 보여준다.

## 영향

Supabase 서버 클라이언트와 인증·소유권 정책을 이 구조 위에 얹는다. 공개 폼과 운영자 콘솔이 같은 출처를 공유하므로 업로드 HTML 격리를 [ADR-003](003-html-contract-and-sandbox.md)에서 따로 다룬다. 관리자 화면의 수치는 초기 구현에서 데모 데이터였으나 현재는 모두 실제 집계 결과다.
