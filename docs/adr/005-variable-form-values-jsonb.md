# ADR-005: 가변 폼 입력값의 JSONB 저장

## 상태

채택

## 결정

캠페인·폼·방문·신청의 관계와 소유권은 정규화된 테이블과 외래 키로 관리한다. 템플릿마다 달라지는 입력 스키마는 `html_templates.input_schema`, 실제 신청값은 `submissions.values` JSONB에 저장한다. 신청 저장 전 Route Handler가 등록된 입력 스키마로 필드 이름·타입·필수값·선택지를 검증한다.

## 이유

템플릿마다 열이 달라지는 데이터를 고정 테이블 열이나 캠페인별 테이블로 만들면 마이그레이션과 조회 비용이 커진다. 반대로 모든 데이터를 JSONB에 넣으면 소유권·캠페인·방문 관계와 무결성 제약이 약해진다. 관계 데이터는 정규화하고 가변 값만 JSONB로 제한하면 초기 범위에서 두 요구를 함께 만족한다.

## 영향

- 입력 스키마가 달라지는 기존 템플릿 덮어쓰기는 지원하지 않는다.
- JSONB 필드별 고급 검색·인덱스·CSV 내보내기는 현재 범위에서 제외한다.
- 운영자 응답은 DB 함수의 `form_values`를 HTTP 계약의 `values`로 변환한다.
